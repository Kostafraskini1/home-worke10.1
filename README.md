# Виджет банковских операций
## Описание:

Проект "Виджет банковских операций" - это веб-приложение на Python
для дополнения новых функций в личный кабинет клиента.

## Установка:

1. Клонируйте репозиторий:

git clone https://github.com/Kostafraskini1/project-init.git

2. Установите зависимости:

pip install -r requirements.txt

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Новая функциональность
В последнем обновлении мы добавили возможность считывания финансовых операций из файлов формата CSV и XLSX. Теперь пользователи могут легко импортировать данные о транзакциях для дальнейшего анализа.

### Как использовать
1. Убедитесь, что у вас установлены необходимые библиотеки:

pip install pandas openpyxl

2. Используйте следующий код для считывания данных из файлов:

import pandas as pd

# Считывание из CSV

csv_file_path = 'path_to_your_file.csv'

df_csv = pd.read_csv(csv_file_path, sep='\t')  # Убедитесь, что разделитель установлен верно

# Считывание из XLSX

xlsx_file_path = 'path_to_your_file.xlsx'

df_xlsx = pd.read_excel(xlsx_file_path, engine='openpyxl')

# Вывод данных

print("CSV данные:")

print(df_csv)

print("\nXLSX данные:")

print(df_xlsx)
