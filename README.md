# Виджет банковских операций
## Описание:

Проект "Виджет банковских операций" - это веб-приложение на Python
для дополнения новых функций в личный кабинет клиента.

## Установка:

1. Клонируйте репозиторий:

git clone https://github.com/Kostafraskini1/project-init.git

2. Установите зависимости:

pip install -r requirements.txt

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Тестирование:

Для обеспечения качества кода в проекте используются автоматические тесты, написанные с помощью
библиотеки 'pytest'. Тестирование охватывает основные модули программы:
-""masks"": Проверка маркирования номеров карт и счетов с различными форматами.
-""widget"": Проверка правильной обработки карт и счетов, а также преобразование дат.
-""processing"": Проверка фильтрации и сортировки трансакций.

## Запуск тестов

1. Убедитесь, что у вас установлен 'pytest'.
2. Запустите тесты с помощью команды: bash
pytest tests/

### Отчет о покрытии

Тесты покрываются не менее 80% кода проекта. Для получения отчета о покрытии можно использовать
флаг '--cov' при запуске 'pytest':bash
pytest-cov=src tests/
